Work

problem → approach → outcome

A social-style feed where every authored post is Ed25519-signed offline and verified in the visitor's browser via Web Crypto. Auto-relayed security news is labeled and never earns the checkmark — view source, it's all client-side.

Problem

Static hosts and CDNs can silently serve tampered content; "trust the server" isn't a threat model.

Approach

Sign posts offline; pin the public key in the page; verify each entry client-side. Wrong key → nothing shows verified.

Outcome

The ✓ attests authorship by one specific key — an origin or DNS compromise can't fake it.
